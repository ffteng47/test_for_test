命令（每跑一次一个 run，全程只读，不动冻结面、不花 B₂、不落一条 event）：

```
python -X utf8 -m plot_engine.counterfactual sampling/t8rN --model-config @router_r1_32b.json
```

工具 `plot_engine/counterfactual.py`：draft 取自逐章快照的 `## Draft`（正文一字不改），
State 由 EventLog replay 到本章开工前，契约对那份 State 重新派生，判定走 `reduce_commit`
（Stage 1+2，无副作用）。抽取通道只换提示词：冻结面 `extract_prompt` **原文做前缀**，
后面追加两张脸的判别段（类型判别 INFERS/BELIEVES 与 OBSERVES 的分界、fact_id 归属规则）。
测试 `plot_engine/tests/test_counterfactual.py` 锁住这条「冻结面做前缀」的纪律。

## 2. 定价：两句，不是一句

| 口径 | t8r1 | t8r2 | t8r3 | 均值 |
|---|---|---|---|---|
| 干净 E2 现值 | 40% | 40% | 10% | **30%** |
| 只算「洞」的翻绿 | 40% | **50%**(+1) | **20%**(+1) | **36.7%（+6.7pp）** |
| 把「少抽」也算进去 | **50%**(+1) | 50% | 20% | 40.0%（+10pp） |

**预注册里那句「从 30% 升至 X%」按实测撤掉**：单一百分比会把两种性质不同的收益合并——
t8r1 唯一翻绿的章不是洞补上了，是新通道**抽得更少**（死人不再被派事件，H1.1/I7 自然消失）。
把「少抽」的价格写成「洞」的价格，等于宣布提示词修复成功了，而它实际只买到 +6.7pp。

## 3. 两条必须随数带走的东西

**(a) 单跑不可复现。** 同一份 t8r1 ch09 draft，两次回放一次判「反事实全绿」、一次判「缺 BELIEVES」
（temp 0.2，r1:32b）。⇒ 本表的章数误差是 ±1 章，而 ±1 章在 10 章分母上就是 ±10pp——
比两栏口径之差还大。这不是补充说明，这是 §7.3 里那条「抽取侧 golden test（同一段推理文稿，
INFERS 与 fact_id 归属逐字可复现）」的成本证明：**不做可复现性，抽取端任何改进都无法定价**。

**(b) 下界。** 90 章次里 7 份快照 `contract_version≥2`（重议过），dump 只存事件类型名，
重议后的契约无法从快照重建 ⇒ 回放一律用 version-1 原契约。`renegotiate_contract` 只删
`required_events`（`revision_actions.py:47`），v1 更严 ⇒ 「洞」那一栏是**下界**。

**(c) 链污染已被工具拦住。** t8r3 的链尾第 9 章是闸口 #2 演练时 `--rescue` 提交的人工稿，
它之后的章 pre-state 含人工 ⇒ 输出直接标「可比 7 章（其后 1 章剔出）」。守卫写在
`price_run` 里：链尾章不在 dump 的 OK 集合里 ⇒ 判定这条链被事后救援写过。不靠约定。

## 4. 这条定价改变了开尺包的重心

§7.3 预注册的两件（提示词判别 + fact_id 归一）实测只值 +6.7pp，而 T8/T9 的判据缺口是
17–23pp。**提示词不是主体**：主体是那条**确定性提升规则**（正文含结论措辞且已抽到 evidence
⇒ 补 `INFERS` 提案）和它的可复现性测试——它不依赖模型肯不肯配合，也就没有 ±1 章的脾气。

下一步（Phase 2 开尺前，按 §7.3 顺序）：先写提升规则 + golden test，再在同一把新尺上
重建 14b 臂 C 基线 ×3（v3 的 47% 归为旧尺刻度），预算 3 + 2 预留、判据公式与 20pp 间距一字不动。
