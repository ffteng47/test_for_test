⇒ 不存在「空指针」级的信息缺口：ID→命题的映射在同一份上下文里可查（两跳，不是零跳）。

**v0-blind 从来不是盲写**：场景规划器把答案键写进了 beats，`_vocab` 无条件渲染。
所以本轮 A/B 的真实对比是「beats 里的答案键」vs「beats 里的答案键 + 两行汇总」，
+10pp 是**那两行汇总的边际价值**，不是「告知 vs 不告知」的效应。
「盲写从来不是产品形态」这句在配置层面已经成立（两组都不盲），但**结论方向要重写**：
本轮无法为「告知 vs 不告知」定论，只能为「显式汇总行 vs 隐式 beats」定论。

  「是叛徒」那条是 F2，且 F2 在 `knowledge_forbidden`）。抽取器只能在词表里挑，
  于是给了 `SUSPECTS fact_000003` + `READS fact_000004`。
  抽取侧**已经有候选 fact 清单带命题**（`extract_prompt` 注入 `已知事实: fact_000001: 宗门内存在叛徒…`），
  所以「给抽取器加候选清单」这个便宜对策**已经在位**，不是可挖的便宜。

四章正文读下来（**这是四章抽样的证据，不是全称证明**），世界 B 未出现：抽取器每次都把正文里真实发生的对象如实登记。
「target 绑错」这个说法作废，正确的说法是**写手没把故事写在被点名的那条命题上**，
而它有两个可分离子原因：角色/态度漂移（ch02/ch04），与夹具把 hard gate 压在了低先验的跃迁上（ch07/ch10）。

**定性修正（审查 §1，t3 自己的数据推翻了绝对化措辞）**：

| 原写法 | 证伪证据 | 修正后的定性 |
|---|---|---|
| F4「承载不了」怀疑这一态度 | t3 ch07 **首轮过**，产物正是 `SUSPECTS fact_000004` | F4 作为 belief 客体**先验低、叙事台阶窄**；五次抽样一次命中，行为上接近抛硬币 |
| F2「只能被推理、不能被观察」 | t3 ch10 rewrite 后过，产物 `READS fact_000002`（要求未删） | 观察/阅读路径**存在**，只是模型默认不走 —— 同为**低先验** |

这条修正决定**修复的性质**：「不可能」⇒ 夹具是错误、必须改；「低先验」⇒ 夹具是高风险设计，改它是降方差，
但同一个 gate 换一条 Arc 未必错。**报告里不许写「夹具错误」**，防止 Phase 1 引用成
「hard gate 不能要求低先验跃迁」的过度推广。正确的通用表述是：
**对低先验跃迁设 hard gate = 把方差引进 E2；修复方式是给叙事台阶，或把它降级为软要求（SOFT）。**
具体两条修复动作不变（见「下一步」第 3 条）。

**backlog #7 就此闭合**：三层里「提示词没给」被否（两跳可查、且 beats 已给），
「抽取漏了」被否（抽取器有词表、产物与正文一致），主因是 **Writer 正文层面的角色/命题漂移**。
**backlog #6 一并定案（措辞按 §1 修正）**：ch07 不是模型不会写 belief（ch03/ch09/ch07-t3 都写出来了），
而是 **F4 作为怀疑客体先验低**——t3 一次命中证明可达，其余四轮落空，hard gate 把它变成了方差源。
**backlog #5 一并定案**：writer 提示词**确实**渲染了本章 required events —— 以 `节拍意图` 的形式
带上事件类型与 fact ID，两个实验组都有。⇒ ARC_CONFLICT 抖动的归因从「引擎没接线」里排除，
落在解码侧（温度 0.8 + 无 seed），这条正是抖动章处置要等 seed/低温对照轮的理由。

## 提交率里有多少是「删要求」换来的（新立，E2 读数的必备注脚）

`renegotiate_contract` **不改正文**，只放宽契约后重新验一遍。六份 dump 逐章比对：
`## Draft` 与 `## Round 0` 正文逐字相同 ⟺ 该章**没跑过任何 `rewrite_*` 动作**（全是 renegotiate，或 0 轮）；
出现任一次 rewrite 的章正文必然不同。**六份采样、零反例**（唯一带 0 轮的例外是 ARC_CONFLICT 章，
它没有修订动作也没有 rewrite，等式两边同时成立）。所以「提交」有两个来源，必须分开记：

- t3 提交 8 章里 **3 章（ch03/ch06/ch09）是正文未改、靠重议过的**；其中 ch06 最终
  `required_events=[]` —— 要求被删空之后空手通过。
- 盲写 s1 为 2/6、s2 为 1/4、s3 为 0/3；t1/t2 为 0。
- ⇒ **t2 的 70% 是干净的**（0 章靠删要求）；**t3 的 80% 含 3 章删要求**。
  这正是预注册把主指标定成首轮通过率的原因；今后每次采样都要并列报这一行。

## 下一步：一次 v3 冻结捆包全部变量（分步采样 = 混淆）

四条改动若分步做、每步后采样，四组读数互相不可比，且每步都要再花三次采样。**合成一次 v3 冻结**，
同一冻结面上跑多臂对照：

| 臂 | 内容 | 面 |
|---|---|---|
| A `v2-stripped` | `节拍意图` 去掉事件类型名与 fact ID（纯叙事意图） | **planner 输出面 = 引擎面**，必须走冻结 |
| B `v1.1-told` | 告知块直接带命题（`必须发生的跃迁: 张三.knowledge「宗门内存在叛徒」→ known`），省掉两跳 | 提示词配置面 |
| C `v1.1-told + persona` | 系统提示加一条角色锚定（「张三是调查方，不是伪造者」），针对 t1 ch02 的角色漂移 | 提示词配置面 |

夹具两条修复（ch07 给 F4 补可怀疑的上位命题 / ch10 把 F2 的实现类型改为 READS∪INFERS 可达）
与上面三臂**同一次冻结**，alignment 记录照走。预算不足就砍到两臂（A / B），persona 并入 B。
3 臂 × 3 采样 ≈ 3 小时本机；v3 之后「告知 vs 不告知」才能落锤。
**冻结说明里要写清这条边界**：beats 渲染归 planner 输出（引擎、冻），persona/汇总行归提示词配置（快迭代、不冻）——
否则下一次又会出现「配置里带着尺」的越界。

其余仍挂着的：
1. seed / 低温对照轮（抖动章处置的前提，v3 之后跑，免得和提示词变量混在一起）。
2. 空契约提交的 Phase 1 裁定（见「E2 口径正式化」）。
