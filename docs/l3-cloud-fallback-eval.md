## 4. 成本测算（按 v042 实测口径）

- 单章判分：prompt ≈2677 tokens（v042 全量均值）+ output ≈800 → ≈3.5k tokens/章
- 云端单价 $0.00041/1k → **单章 ≈$0.0014**；50 章全量 ≈**$0.07**
- 推荐混合路由下云端用量 <5% 章节 → **月成本 $0.01 量级**，成本不是决策变量
- 真正的管理项=**读数口径**：换模型=换读数（R2 纪律），云端模型版本随服务商升级漂移
  ⇒ 云端读数独立带戳（model@host+版本日期）、独立过 ch50 锚闸、与本地读数**分表不混秤**

## 5. 与既有纪律的兼容性

- **核验器降级不退休**：云端不可用/超时 → 判分器降级为 unavailable observation，管线不崩
  （inkos `chapter-review.ts` 同构互证；Oh Story `tool_unavailable=3` 出口码同构——工具坏≠正文要改）
- **判分器不进内核**：云端判分仍留 sampling/ 旁路车道（设计 §3.3），生产接线=批5 另案申报
- **temperature=0 有利**：deepseek 配置已贪心——丁批归因混淆①（temp≈2.0 采样漂移）在云端侧天然消解
- **候选不是定罪**：云端判分输出同样 severity 恒 OBS，二审意见不自动升 HARD

## 6. 推荐形态与待拍

**混合路由**：本地 32b=默认判分端点（$0、数据不出机）；云端=仲裁（尺面换代）+二审（存疑/深档/洪峰章）。
这与 inkos「审稿失败降级」+AI-NWA「debt 章强制人工复核」+Oh Story「五态出口码」三件互证形态同构。
