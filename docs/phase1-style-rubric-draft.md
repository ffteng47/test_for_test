# Phase 1 文体 rubric 草案（T6）

> 状态：**草案，待 tff 定标**。这份不是判据、不进任何闸口，只把「愿意付费读的下限」变成可数的六条。
> 立条纪律：每条都必须是**人工抽检已经抓到过**的缺陷类，且**现尺看不见**（看得见的归 H 规则，
> 重列就是拿新尺替换人工抽检——§7 防线禁止的那件事）。凭据列在每条后面。

## 1. 六条（逐章二值判定：过 / 不过）

| # | 条目 | 判法（读 `## Draft` 正文，不看提案不看判据） | 凭据 |
|---|---|---|---|
| R1 | **不复述** | 同一场景没有出现「同一批信息被近似重写 2–3 遍」的段落组 | backlog #11；v3 臂 A 抽检三章全部可见（`phase0-v3-three-arm-results.md` §4） |
| R2 | **立场不漂移** | 主角的身份/阵营全章一致，没被写成自己所查案件的作案方 | `b2 ch02` 把调查方张三写成伪造者本人，而该章 H5.x 全绿（§4 人工抽检唯一一件尺看不见的事） |
| R3 | **名物与数量自洽** | 同一件物品/同一个数在全章只有一个指称与一个值 | T8 一发核实的 r1 正文里同一枚印章同时叫「十八号印章 / 第十七枚印章 / 印章17」，且 17 与 18 互相矛盾 |
| R4 | **不泄元数据** | 正文里没有标记、注释、标题、小标题、"本章悬念"一类非叙事文本 | `_clean` 只剥 HTML 注释与超长，其余泄漏靠人眼；`llm_writer.py` 提示第 3 条 |
| R5 | **段长与体量合规** | 2–4 个自然段、单章成文且不超预算字数（超长被截不算过——截断是工程事实不是文体选择） | `_clean` 的 `max_chars` 截断会静默吃掉正文尾部（backlog：`rewrite_scene` 名义阶梯同源） |
| R6 | **单章可读** | 一个不了解 State/契约的读者，读完这一章能说出「谁在查什么、这一章新发生了什么」 | 臂 A 的真盲写面（`stripped`）本来就是为了测这条能不能离开答案键成立 |

**不过的线**：R1–R6 全过才算该章「过」。定标动作 = 10 章盲读，**≥7 章过** = 这套产物达到
「愿意付费读的下限」；这条线由 tff 拍，不是由我拍。

## 2. 采样期怎么用（只写结论口径，不改判据）

- 与 §7 防线 2 的**逐臂分层 3 章人工阅读**同一批读次做，不另开一轮人读：读的时候顺手按六条打勾。
- 报告里 rubric 结果**单列一行**，不进 E1–E6、不进 G1–G4、不作 C 形态的加分依据
  （T4 推迟的同一理由：一把未校准的尺不能进判定面，误报率未知）。
- 校准动作：三次产品形态采样共 30 章次全读一遍，统计每条的通过率与相互独立性；
  某条常年全过或常年全不过 ⇒ 说明它没信息量，定版时删掉（删条目不需要新授权）。

## 3. 反复述约束实验（backlog #11 的首个低成本实验）

- 改动面：`scene_writer` 系统提示加一条禁复述条款（现 5 条 rules 之后追加一句），**尺一字不动**。
- 对照：同 router、同解码参数，抽 3 章（章号固定写死，不临场挑），逐章按 R1 判过/不过。
- 定性：提示词是产品配置不是协议（`llm_writer.py` 顶部注释已确立这条先例），
  所以它属 alignment 之外的**产品变量**——实验结论只进文体线，不进一致性判据。
- 前置：这个实验要烧 LLM 预算，排在 T8/T9 之后（B₂ 预算 6 次 / 上限 8 次先给判定用的）。

## 4. 现在不做的

- 不做「复述度自动检测器」：R1 的判法是人眼，自动化要先解决「同一批信息」的表示，
  那是第二把未校准的尺。等 §2 的 30 章次读数出来，若 R1 通过率高且误报可控再谈。
- 不给 rubric 加权分：六条二值全过才算过，加权就是把它变成连续指标，反而没法和「愿意付费读」这句话对上。
