① A（第一次真盲写）是三臂最低（严格口径均值 23% vs B 53% / C 43%），而且它的低分不只是

就跟着一起消失；把它留下就不再是「盲写」（这条边界单立为 #13）。arc 本身可满足，B/C 就是证据。
这条是本轮对产品最硬的一句：**告知型 writer 不是可选项**。

② persona 块（C）没有换来指标增益（均值 43% < B 53%；逐份对齐三份里有一份反向，
所以只记「未换来增益」，不记「无效」，见 §6）。

90 章审计），再让驱动跑完 + 作废臂补跑，同面可比性没有被「中途换尺」污染。
补跑台账（每臂要 3 份完整读数）：臂 A 得 a2/a3 ⇒ 补 **v3a4**；臂 B 得 b2/b3（b1 作废）⇒ 补
**v3b4**；臂 C c1–c3 全活 ⇒ 无需补。**计划总启动 = 9 + 2 = 11，实际 11**。
**上限是硬的**：若臂 C 也作废两次（总启动需 13），不越界补跑，直接按「C 只有 2 份读数」
报不可判并给出方差 —— 预算条款本身就是判据的一部分。本轮未越界，故按 n=3 落判。

**按一致性铁律的定位**：`v3a4` / `v3b4` 是**作废运行的替代**，不是「读数不一致后补一份凑多数」。
但臂 A / 臂 B 各自恰好只有三份完整读数（作废那次没有读数可剔），严格执行条款会把 A/B 的投票集
压到 n=2 ⇒ **本轮不存在同时满足「三份投票」与「补采不投票」的构造**。两种取法都在 §3 表后并列算出，
逐行落判相同；本档主表取「每臂全部三份完整读数」，并在表内标明哪两份是补跑。

**投票集的构造（两条规则各自都没被违反，只是它们的字面合取凑不出 n=3）**：
本轮有两条独立的预注册规则在管这件事，先把它们分清楚，免得下次再争议 ——

严格执行 ② 会把投票集压到 n=2，与「每臂三份」冲突 ⇒ **本轮不存在两条都字面满足的构造**。

## 6. 结论与下一步

> **本节含优先级与机制定性（建议性质，非数据）。落判以 §3 为准，数据以 §2/§5 为准。**
> 判据一条未动；本节只做「哪些话可以写、哪些话不能写」的边界标注。

**可以写的（不越界）**：
- 三臂首轮通过率：A 23% < C 43% < B 53%（严格口径），扣判死口径同序 ⇒ 「告知写手本章要求」
  对首轮通过率有正向作用的**方向**成立，`C ≥ A` 逐份三次全对。
- **B−A ≈ 30pp（严格）/ 24pp（扣判死）**：语义是「任意形式获知要求」的总效应（§10.4），
  与 v2 的「汇总行边际 +10pp」不是同一个量，不得互相替换。
- 防线 1 通过（H5.7 提交章泄漏 9 份全 0）；防线 2 通过（每臂 3/3 成文）；两处尺洞修复对
  已完成读数逐条等价（90 章审计）。
- **「告知型 writer 不是可选项」**（产品结论，本轮最硬的一句）：依据是 ch01 的 3/3 vs 0/6
  —— 同一份 Arc、同一套判据、同一个模型，只在「节拍行给不给事件类型」上不同，第一章就从
  100% 判死变成 100% 可提交。这句是**配置面**的结论（要求必须传达），不是「模型会写」的结论，
  不得写成「盲写不可行 ⇒ 模型不行」。

**不能写的**：
- 不能写「主指标达成」或「persona 有效/无效」—— 主指标被逆激励护栏降格为**不下判定**，
  且 C 三份无一 ≥60%；persona 的 C−B = −10pp 小于 B 自身 30pp 方差，在该设计下不可分。
- 不能写「自动修复达标」—— E3 九份最终提交率无一 ≥90%，且「修复率」里有 7 章次是删空判据
  换来的，不是改写正文救回来的。
- 不能取多数、不能合并出单一数字、不能说「基本一致」。本档九份全量并列。

## 7. Phase 1 立项条款（判据已冻结，2026-10-11 裁定）

> 本节把 §6 的「不放弃」写成一个可执行、可终止的条款。**立项条款的意义在于：架构降级
> （hard gate → soft gate + 人工终审）只能由「带预算的失败」触发，不能由一份低于预期的读数触发。**
> 两个预算数字（B₁ / B₂）与触发线 (ii) 的口径已按裁定落定 ⇒ **本节起逐字执行**；
> 之后任何改动都要在本节留下改动原因，不得静默换线。

**预算（两个数字写死，无上限的条款不构成 kill criterion）**：
- **B₁ 工期上限 = 2–3 个工程周**（单人兼职口径）。范围而非工时：四个工作流 —— #9 修复（小）、
  #12 命题入汇总行（配置，小）、needs_human 路由（小-中，见下面「交付物」）、
  #8 seed/低温与更强模型对照（采样密集，机器约 1 天）。
- **B₂ 算力上限 = 8 次启动**（重采 6 + 每配置预留 1 次作废；见下面「重采取甲」）
  ⇒ **≈ 2.4h 机时**（按本轮实测均值 1066s/份外推；按观测上界 1268s/份则 ≈ 2.8h），
  本机 `qwen2.5:14b`，**现金 ≈ 0**。若变体改跑云端强模型，B₂ 换成美元预算，
  按本轮实测 token 量估（单份 10 章 ≈ 3.7–4.7 万 token）⇒ 上限几十美元量级。

**重采取「甲」已裁定（2026-10-11）：被测配置 = 产品形态 + 模型/解码变体，各 n=3；臂 A 不重采。**
理由不是「省一小时」，而是 **kill criterion 的判线是绝对线、不是差值线**：它把 Phase 1 末态读数与
**已冻结的 v3 基线**比（E2 对 70%、处置率对基线 − 20pp），判定生死不需要同期对照组。
- **臂 A 排除**：stripped-blind 是诊断臂，产品不会以盲写形态出货；末态再测一次只得到一个
  没有决策价值的「盲写依旧不行」。从 9 砍到 6，砍的是零信息量读数，不是对照完整性。
- **对照 3 次给模型/解码变体**（#8：seed/低温 **或** 更强模型，二选一，随形态一并冻结）：

  选 seed/低温则是纯配置改动，无外部依赖。
