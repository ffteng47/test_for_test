## 出题时已知的混淆（读答案键前先认这笔账）

**章长跟着模型家族走**，所以「愿意付费读」的分数会经由长度而不是文笔来区分跑法：

| 跑法 | 家族/配置 | 有正文字数区间 | 中位 | 失败类章数 |
|---|---|---|---|---|
| ladder2_r1 / r2 / r3 | qwen2.5:14b @11500，夹具 ladder-v2 | 773–1164 | 941 / 978 / 995 | 5 / 4 / 3 |
| v32r1 / r2 / r3 | qwen2.5:14b @11500，夹具 ladder-v1（尺 v3.2） | 726–1280 | 1028 / 903 / 942 | 4 / 4 / 3 |
| bo_ctrl | qwen2.5:14b 控制臂 | 896–1074 | 997 | 5 |
| bo_q3_30b_a4000 | qwen3:30b，`a4000` 采样 | 1685–2112 | 1863 | **10** |
| bo_q35_27b | qwen3.5:27b | 2264–2987 | 2685 | 5 |

两条后果，读数时必须分开：
1. **长度自变量与模型自变量重合**——想读「27b 是不是更好看」，绕不开「27b 平均长 2.7 倍」。
   要拆开只有一个办法：盲评打分之外**单独记一列「长度是否影响你的判断」**，别指望从总分里减掉。
2. **a4000 那臂 10/10 全是失败类**——它单独把「判死的章是不是真难看」这一格做成了纯失败样本，
   读它得到的负分不能当成「30b 写得差」，只能当成「判定器与人在这一臂上同意」。

`bo_q3_30b` 被排除出题：10 个 dump 全都没有正文（只有判定，没有文本），凑不进分母。
