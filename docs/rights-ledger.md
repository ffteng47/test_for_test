# 权利台账（M5-④）

**这不是法务文书，是一张开工前的表。** 卖的是母带不是软件，所以「权利由委托方持有并书面担保」这句话必须落到一个填完的文件上，否则它只是报价单里的一句话。`monetization-wiki.html` §13 缺口 5 标的原话是**完全空白**：文本授权合同模板、`voice_extract` 声纹来源台账、AI 朗读披露元数据，三样都没有落库。这一节把三样各钉在一处。

判据本身是硬的：**缺任一条不开工**。拿网盘文本做样音去接单，性质从「个人学习使用」升级成「营利性侵权」，责任落在制作方；Audible/ACX 这类正规渠道「上架即下架 + 封号」。

## 1. 落库位置与命令

台账是**一本书一份**：`alexandria/projects/<slug>/rights.json`，和 `delivery_report.json` 同级。认书的唯一入口是 `projects.json` 的 `active`——和审听记录同一口径（`chunks.json` 在共享根上是**真文件**，靠 `realpath(CHUNKS_PATH)` 反查会串书）。

在服务器上（只读检查，不改后端、不需要重启）：

```bash
cd /home/tff/software/novel-audiobook/alexandria/deploy_patches
../venv/bin/python check_rights.py                  # 查当前 active 书
../venv/bin/python check_rights.py --slug <slug>    # 查指定书
../venv/bin/python check_rights.py --slug <新书> --init   # 写空模板（已存在就不覆盖）
../venv/bin/python check_rights.py --demo           # 自检：负例必须 7 条 FAIL、正例必须 pass
```

退出码 0 = 可开工，1 = 不开工。源码 `deploy/check_rights.py`，部署到 `alexandria/deploy_patches/check_rights.py`。

**实测（2026-10-11）**：对当前在盘的那本书跑 `check_rights.py` → `缺 rights.json → 不开工`（退出 1，正确）。

## 2. 三条判据

| 判据 | 要什么 | 为什么要 |
|---|---|---|
| **① 文本权利** | `原文来源.途径` 不是网盘/转载口径；`改编权 + 信息网络传播权 + 声音表演` 三项 `true`；`客户.权利担保` 有**书面担保**且**侵权自担**；`客户.合同` 给出凭证文件名 | 三个权利缺一个都上不了架；「有声改编权」在网文平台通常要并入内容授权合同，个人绕不过平台 |
| **② 声线来源** | `voice_config.json` 里每个 `type == "clone"` 的角色都要有一行；`来源 ∈ {自研音色, 授权样本}`；`授权样本` 必须 `商用=true` + `凭证`；**参考音频不在 `designed_voices/` 下却按「自研」填的，直接拦** | 声音使用权与文本版权是**两个独立权利**，常被漏掉；本流水线的 persona 那一步是「造声再克隆」，得能证明造的是自己的 |
| **③ AI 朗读披露** | `披露.声明文本` 非空 | ACX 2026-04-15 起写明音频须真人叙述（除非另行授权，那条通道是 Audible 自有的）；我们卖的是 AI 母带，不披露就是欺骗渠道 |

`记录.复核` 为空只给警告，不拦——它是**模板**，定稿要过法务，但不必卡住第一单。

## 3. 本流水线现在的声纹状态（实测）

`projects/shuxue/voice_config.json` 8 个角色（`NARRATOR / TONGSHU / XIAOMAN / YUNWEN / XIAOMAN2 / MAMA / GIRL / CROWD`）**全部 `type = clone`**，但参考音频一律是 `designed_voices/<角色>_<id>_preview.wav` —— 即 `persona` 那一步用 VoiceDesign 造出来、再拿回去 clone 的音色，**不是任何真人的声纹**。

结论：这本书的声纹风险是**零**，但「零」这个字必须有凭证撑着，所以台账里每个角色填 `来源 = 自研音色`、`凭证 = 那个 preview 文件名`。判据用 `ref_audio` 的路径来认这件事：一旦哪天改成拿客户的真人样本做克隆，同一个检查器就会把它按「授权样本」拦住，要求单独的商用授权。

> 顺带一条与前端一致的口径：导出的 M4B 元数据 `演播 AI · Qwen3-TTS` 是**对内标记**，对外还得有 `披露.声明文本` 那份能贴进详情页的话。两者不是同一件事，别拿前者当披露。

## 4. 模板文本（写进合同，不是写进台账）

台账只记「有没有」这几句，句子本身在下面。合同条款：

> 委托方声明其持有本作品原文的**改编权、信息网络传播权及声音表演权**，并保证上述权利真实、有效、无瑕疵；因权利瑕疵引发的任何争议、下架、索赔及合理维权费用，由**委托方承担**并使受托方免责。委托方另行指定克隆特定真人声线的，须就该**声音使用权单独书面授权**，该授权与文本版权相互独立。
>
> 本作品音频由 AI 合成朗读，**无真人演播**；受托方有权在成品元数据与详情页作此声明。

**这是业务口径的草稿，不是法律意见。** 首单之前把这段连同 `--demo` 的判据一起给法务过一遍，改完把定稿文件名填进 `客户.合同`。
