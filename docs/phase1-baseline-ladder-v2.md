## 2. 按判据下结论：**不可判**，且夹具改动没有可测效果

- **一致性铁律**：E2 极差 20pp > 10pp ⇒ 报方差、不下结论。处置率极差同样 20pp。
- **对 v1 同端点控制臂**（`q25_11500_r1–3`，E2 60/70/50 均值 **60.0%**、处置 40/30/50 均值 **40.0%**）：
  本臂 E2 56.7% vs 60.0%（差 3.3pp）、处置 40.0% vs 40.0%（差 0）——**两臂自身极差都是 20pp**，
  按 phase0 §7 第 3 条「臂间均值差 <15pp 一律不读」⇒ **读不出夹具改动的影响**。
- **章级**：ch07 首轮 v1 **0/7** → v2 **1/3**（r2 首轮通过）。双侧 Fisher **p≈0.39** ⇒ 方向对、样本不够。
  这一格没变成 E2 的增益，是被别章吃掉了：r2 的 ch01 判死（`ARC_CONFLICT`）、r3 的 ch06/ch10 停在处置。

⇒ **结论：ladder-v2 既没有坏效果，也没有可测的好效果。** 它应当保留（戏剧论证独立成立：
不能要求主角「怀疑」他上一章刚亲手读实的事实），但**E14 当年给它定性的「每臂白吃一章处置税」是错的**
（勘误账 E17：那条纪律说的「每一条臂」我只查了同端点一族，而 v1 夹具下 `t8r1`、`v32r1` 的 ch07
是 `rounds=0` **首轮通过**）。

## 3. ch07 真正的漏点在抽取面与尺的文本上（本轮唯一的新知识）

r1 的 ch07 两轮都没过，Findings 是 `H5.1 必需事件 SUSPECTS 数量不足（0<1）` + H5.3 下游，
而它的正文明明写着「他开始怀疑，守阁的人是否与印章目录中的伪造品有着千丝万缕的联系」——
**抽取器对这段只吐出 `OBSERVES`/`INFERS`，一条 belief 族事件都没有**（终轮 Proposals 实测）。
两处供给侧缺口叠在一起：

1. `FIX_GUIDE["H5.1"]`（`review.py:182-184`）把六个事件类型逐一解释了怎么写，
   **唯独没有 SUSPECTS**；而 ch07 是全夹具唯一必需 SUSPECTS 的章。同一段里的 H5.3 指引反倒写了
   `belief→Believes/Suspects/Doubts` ⇒ 两条指引对同一类型口径不一致（勘误账 E18）。
2. 抽取提示词（`llm_extract.py:224-251`）只给**裸类型名列表**与 payload 键，
   三兄弟 BELIEVES/SUSPECTS/DOUBTS 之间没有任何可区分判据。
3. 词表本身逼出错挂：SUSPECTS 的 payload 只收 `fact_id`，而正文怀疑的是「守阁人=内应」这个
   **人-动机复合命题**；全库 ch07 抽出 SUSPECTS 的跑法里，它挂在 F4/F2/F3 上都有（`t8r1` 甚至
   `target=char_000009`），挂对与否纯看模型把怀疑对象说成哪个已建档的 fact。

**所以 ch07 的处置税不是夹具欠的，是抽取层欠的。** 这条把 P2（抽取工程化）从「优化项」提为
「ch07/ch09 税的唯一实际解法」：改夹具已经证伪，剩下的可动面只有尺。

本轮**不定因**（勘误账 E20 立了防线：`用时` 跨日不可比，任何「某个改动导致变慢」的说法
必须先出示调用次数与每调用延迟）。r2/r3 的调用次数取不回来是 E21 那次自我覆盖造成的，不是端点问题。
