## 4. 判定（§7 两条判据线，基线取 D1 冻结值）

- **判据 (i) 干净 E2 三次均值 ≥70%** → 实测 53.3% ⇒ **不过**（差 16.7pp，单靠 r2 的 60% 也够不着）。
- **判据 (ii) 处置率 ≤ 基线 − 20pp**：基线 = 名义 15/30 = 50% ⇒ 线画在 30%。实测均值 46.7%，
  最好的一轮 40% ⇒ **不过**。
- 换算那条局限照抄 D1 冻结记录：本表是「同一批读数的终态重读」，未模拟不提交章的 State 后效。

结论一句话：**现尺下臂 C 两条线都不过，而且不是因为修订循环坏了**。逐章修订账：
r1 需修 6 章 / 最多 3 轮 / 修复率 0.17，r2 需修 7 章 / 最多 3 轮 / 修复率 0.57，
r3 需修 5 章 / **最多 1 轮** / 修复率 0.00。r2 证明同一套动作机器真能把章改绿（救回 4），
r3 的 0 救回不是写手退步，而是升级路径提前把章交了出去（无一章进过第 2 轮）——
方差来自「哪一章拿到第几轮」，不来自判据线本身。瓶颈在进修订循环之前就已经判错的那批章，
也就是抽取洞（`docs/phase1-t8-variant-r1-32b.md` §6）。
