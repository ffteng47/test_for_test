## §A1 有声书赛道选题 SOP（四步法移植）

移植 oh-story 选题四步（digest §2.1，story-long-scan/SKILL.md + topic-decision.md:18-43），
按我方赛道改写两处：验证动作与样本口径。

1. **能爆的原因**——先当假设，登记时必须带标记「待样章验证」；禁止把直觉写成结论。
2. **市场验证（含反例核源）**——硬闸沿用稀疏度纪律：同方向对标作品 **<15 部**（小平台 <10）
   标「样本少」，可行性**最高只给"中"**；单本排名只算线索，近期多榜单/多作品的**重复模式**才算趋势。
   内置知识（未联网核实的判断）必须标注「未完成实时校验，只作候选假设」。
3. **差异化定位**——写不出「相对已验证作品我不同在哪」= 同质化，回炉。
4. **可行性 + 失败风险 + 低成本验证**——原文「先写黄金三章测追读」替换为我方等价物：
   **先出 3 章样章走完有声交付链，测听服完读/停留**，不行就换方向。

出口形态：一页选题决策记录（四步各一行结论 + 证据链接/样本数），落 `docs/` 选题档。

## §A5 门禁分层设计原则（入 Phase 1 闸口设计参考）

三句话原则（digest §2.3）：
1. **两层分工**：写前门（前置物完备性，拦「没细纲就动笔」）+ 写后兜底网（落盘后只跑硬信号轻量确定性检查）——
   两层各自声明绕过边界，advisory 类留到收尾全量跑；
2. **宁可漏拦不可误伤**：检查器任何不确定一律放行（exit 0）——与我方「伪定量不阻断」（04:82-83）同律；
3. **只判结构不判值好**：字段必须在场、值可写「[待补充]」——对应我方 Validator「Commit 前确定性闸门」哲学，
   新增「写前门」实现即 B4（另批申报，本文不实施）。

## §A6 决策笔记纪律（候选入我方 docs 流程）

oh-story 用 `.agents/notes/` 74 篇，三态机：**proposed / implemented / rejected**；
两条硬规矩值得直接采纳：
- 被否方案（rejected）必须先写**它的最强理由**再写否决依据——防止后人把否决当偏见；
- 决定翻转**另开新档互链**，不改写原档——决策史可回溯。
我方对应物=拍板记录模式（本文 §A2、r8-2 pack 拍板记录即实践）；提议：后续所有「保留选项」登记
按 rejected-先写最强理由的格式补强（零成本纪律，即日起适用）。

## §A7 预注册可证伪实验协议（归档，供 WP-C 激活与模型面实验）

oh-story 降 AI 味三组干预实验（digest §2.3，rejected/…ai-flavor-prompt-interventions.md:9-30）的方法论骨架：
- **主指标与门槛在数据产生之前冻结**（例：比对照少 ≥1.0 项且三本至少两本同向）；
- 多臂对照 + 全部未过门槛 → **判负不合入**，实验档进 rejected 态留痕。
我方已有同族实践：E1–E6 判据冻结、三采样「只按一致性下结论」、S 批止损条款、E2 阈值先于批写入闸单。
补强的两条：① 阈值/判据冻结时点=**发射前**（我方闸单机制已覆盖，明文对齐）；
② 判负实验**入档不合入**且先写被否方案最强理由（接 §A6）——建议 WP-C 激活批直接引用本节为模板。
